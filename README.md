# Game-Rock-Paper-Scissors-
A classic Rock-Paper-Scissors game built with Python. Play against a computer opponent with randomized moves in your terminal.

## Project Description

this is a Python-based implementation of the popular game "Rock - Paper - Scissors". It provides the opportunity to pplay this game against a computer, which makes its moves based on random choices. This project is an excercise for students who already grasp the Python basics and want to dice into somethign more challenging and hands-on.

## Requirements
python 3.7+

## Running the Project
Because the game file is inside the src folder, you need to navigate to that folder or run it from the root directory.

### step 1
```bash
python src/game.py
```
### step 2
```bash
cd src
python game.py
```

## How to Play

1. Run the game using the instructions above.
2. When prompted, type your choice: rock, paper, or scissors.
3. The computer will randomly select its move.
4. The winner of the round will be displayed.
5. Type "q" or "Q" to quit or exit to stop playing. 
6. Enter any other key to play agian
